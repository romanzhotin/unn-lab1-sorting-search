# Лабораторная работа №1. Сортировки и поиск

Программа на C для сравнения алгоритмов сортировки и поиска. Считает время работы, количество сравнений и перестановок, а также строит графики прямо в консоли.

## Как собрать и запустить

Для сборки нужен `gcc` и `make`.

```bash
make
./unn-lab1
```

Очистка скомпилированных файлов:

```bash
make clean
```

## Что реализовано

* Сортировки (6 шт.): Пузырьковая (оптимизированная), Шейкерная, Вставками, Слиянием, Быстрая (Хоара), Поразрядная (Radix Sort).
* Поиск (2 шт.): Линейный, Бинарный (с автосортировкой копии).
* Статистика: Вывод времени, сравнений и перестановок.
* Графики: Горизонтальные диаграммы из блоков █ для визуального сравнения.
